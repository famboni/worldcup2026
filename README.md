# World Cup 2026 Prototype

Current milestone: **v0.2 Tournament Prototype**

## Included now
- Browser-based friendly match setup
- Tournament prototype with 3 additional modes:
  - Mode A: one team only
  - Mode B: choose a team every match
  - Mode C: watch mode
- Sample pool of national teams
- 12-team prototype World Cup structure
- Group tables and knockout progression
- 2D broadcast-style UI
- 8-square shot/save interaction
- Short event-driven match flow
- Half-time, extra time, and penalties
- Tactics and substitutions
- Injuries, yellow cards, red cards
- Taidghfantino rule popup using the provided photo
- Local save / resume in browser storage
- Improved music/sound toggles

## Still not built yet
- Full 48-team 2026 World Cup structure
- Proper art/animation polish
- Expanded player/team database
- Advanced tournament presentation screens

## Run locally
From this folder:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open `index.html` through the browser preview.
